# vteamfit-app-v2

VTeamFit App MVP 2026 — Plataforma de entrenamiento de alto rendimiento dirigida por Victoria Torres & Tito Allemandi.

## Arquitectura
- **Framework:** Next.js 15 (App Router) + TypeScript + Tailwind CSS v4
- **Paradigma:** Server-Driven UI (SDUI) + KISS (Zero Mock Data)
- **Base de Datos:** Supabase PostgreSQL (Esquema aislado `v2`)
- **Sistema de Diseño:** W3C DTCG 2025.10 + OKLCH + Fluid `clamp()` + CUBE CSS (`DESIGN.md` v2.0)
